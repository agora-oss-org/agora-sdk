# Sync `agora` with upstream v7.6.2 — merge design

**Date:** 2026-06-27
**Author:** Jenova Marie (with Claude)
**Status:** Approved (brainstorm) — pending spec review

## Goal

Merge the 46 new upstream commits (v7.4.2 → **v7.6.2**) on `main` into the `agora`
working branch, adopting upstream's new features while preserving Agora's four (now
five) documented divergences. Release the result as Agora **v1.4.0**.

## Background — why this sync is "complicated"

The replyke→sublay rebrand is **already absorbed**. Two weeks ago it was recorded onto
`agora` via `git merge -s ours` (commit `a77f09b`) and the tooling/docs were taught about
`@sublay` (commit `9fdc054`). Verified: the current merge-base (`e84eeae`, v7.4.2) is
**already `@sublay`**, so merging `main` does *not* re-drag the whole-tree scope collision.

The real complication is **identifiers**, not scope:

- Agora's standing convention (CLAUDE.md): *"keep upstream's `Replyke*` identifiers; only
  the package **scope** is rebranded."*
- But upstream's rebrand renamed the **identifiers too**: `ReplykeProvider`→`SublayProvider`,
  `useReplykeSelector`→`useSublaySelector`, `ReplykeContext`→`SublayContext`, etc.
- `rename-to-agora.sh` only rewrites **quoted `@scope/` import specifiers**, not identifiers.
- The `-s ours` rebrand merge dodged this for v7.4.2 by declining *all* rebrand content.
  Now we are pulling **new upstream code built on `Sublay*` identifiers** (push
  notifications, events, live conversation list), so the identifier mismatch can no longer
  be dodged. A plain `git merge` + rename script yields a tree that **does not compile**
  (~40 files reference `useSublaySelector`, `SublayContext`, `useSublayDispatch`, … which
  do not exist in agora's `Replyke*` tree).

There is a clean **1:1 `Sublay* ↔ Replyke*` mapping**, and agora already uses the `Replyke*`
side everywhere (`useReplykeDispatch` 38 files, `useReplykeSelector` 32, `ReplykeState` 15,
`ReplykeProvider` 12, `ReplykeContext`/`ReplykeIntegrationProvider`/`ReplykeStoreProvider`…).
So identifier reconciliation is **deterministic and scriptable**, not a judgment call.

## New upstream features in this delta

- **Push notifications** (PR #29) — `PushTokenAdapter` interface + `usePushRegistration`,
  per-platform adapters (core / react-js `webPushTokenAdapter` / react-native / expo)
- **Events bundle** (PR #27) — `EventProvider` + events hooks
- **Comment sorting** — `createdAt` sortBy + `sortDir`, controversial sort, deprecate

- **Entity `createdAt` sortBy** with `DeprecatedNewSortBy` alias (PR #31)

- **Space-list fix** — only send space boolean flags when strictly true (PR #30)
- **Test-coverage** expansion across core/react-js/react-native/expo (PR #28)

## Decisions (from brainstorm)

1. **Venue:** isolated git **worktree** off `agora`; agora's live tree stays untouched until
   the merge is green, then fast-forward.
2. **Version:** semver **minor → 1.4.0** (additive, backward-compatible features).
3. **Rigor:** full SYNCING.md flow + `pnpm run build-all` + `pnpm run typecheck` green before
   any commit; confirm all divergences survived.
4. **Identifiers:** **extend `rename-to-agora.sh`** with a case-preserving
   `Sublay→Replyke` / `sublay→replyke` identifier rename. Divergence #2 grows from
   "scope only" to "scope + identifiers." Mechanical, documented, scales to future syncs.

## Extended rename script — design

Add identifier rules to `rename-to-agora.sh`, **after** the existing quoted-scope rules
(so `@sublay/` → `@agora-sdk/` runs first and is removed before the identifier pass):

- PascalCase / hook identifiers: `\bSublay[A-Za-z]*` → `Replyke…`, `\buseSublay[A-Za-z]*` →
  `useReplyke…` (case-preserving the `S`→`R`).
- Lowercase camelCase store vars: anchor to `sublay` **followed by an uppercase letter**
  (`sublay(?=[A-Z])`, e.g. `sublayApi`, `sublayStore`, `sublayMiddleware`, `sublayReducers`)
  → `replyke…`. The lookahead deliberately **excludes** `api.sublay.io` (followed by `.io`,
  lowercase) — those URLs are declined by divergence #1 anyway.

**Must NOT touch:**
- `@sublay/` quoted scope (already handled → `@agora-sdk/`).
- `Modified from original @replyke/core` attribution prose (says `replyke` already; never
  matched by a `sublay→replyke` rule).
- `api.sublay.io` brand URLs and `sublay-io` PR-merge strings (the latter live only in commit
  messages, not source).

Keep idempotent (`bash -n` clean; a second run is a no-op) and update the leftover-count grep
+ success message to mention the identifier rename. The `pnpm run build-all` + `typecheck`
pass is the safety net that proves no stray `Sublay*`/`sublay*` identifier survived.

## Execution plan (SYNCING.md flow, in a worktree)

1. **Worktree:** create a throwaway worktree off `agora` (e.g. `../agora-sync-v762`).
2. **`main` current:** `git fetch upstream`; `main` already == `upstream/main` (verified 0/0).
3. **Merge:** in the worktree, `git merge main`.
4. **Resolve conflicts:**
   - package.json ×5 → keep `@agora-sdk` scope, set `version: 1.4.0`.
   - `pnpm-lock.yaml` → defer; regenerate in step 6.
   - 4 source files → per the resolutions above.
5. **Extend + run rename:** update `rename-to-agora.sh` with the identifier rules; run it;
   confirm leftover count `0`.
6. **Relink + verify:** `pnpm install` (regenerates lock); `pnpm run build-all`;
   `pnpm run typecheck`. Must be green. Grep confirms **0** `Sublay`/`sublay` identifiers and
   **0** `@sublay/` in `packages/`.
7. **Verify divergences:** base-URL (4 files), auth-flow (#3), `useEntityData` include (#4),
   ranking algorithms (#5) all intact.
8. **Docs:** update CHANGELOG.md (`[Unreleased]` → bullets, then cut to 1.4.0), CLAUDE.md +
   SYNCING.md (5 divergences; #2 = scope + identifiers; upstream-remote line).
9. **Land:** bring the merge back onto `agora` (fast-forward), then version/tag/release via
   `scripts/release.sh` — **as a separate, explicitly-approved step** (no auto-commit;
   per Jenova's no-mid-task-commit rule, ask before committing).

## Success criteria

- `pnpm run build-all` and `pnpm run typecheck` both green.
- `0` `@sublay/` quoted scopes and `0` `Sublay`/`sublay*` identifiers in `packages/`.
- All 5 divergences present and intact; the 4 base-URL + auth files unchanged in behavior.
- `rename-to-agora.sh` idempotent (second run: 0 leftovers, no file changes).
- CHANGELOG / CLAUDE.md / SYNCING.md reflect v1.4.0, the new features, and the 5-divergence
  + scope-and-identifiers reality.

## Out of scope

- No native-ESM/CJS packaging fixes (see docs/KNOWN_ISSUES.md — deliberately unfixed).
- No renaming agora's public `Replyke*` identifiers to `Sublay*` or `Agora*` (rejected
  Option B; a separate project if ever desired).
- No UI packages (`packages/ui/*` remain unbuilt upstream leftovers).
